# kb/jobs · AI 产品经理岗位知识库

本目录是「AI PM Job Retrieval Lab」的语料库：按**公开招聘岗位快照 / 整理要点**收录 11 份 AI 产品经理岗位 Markdown。它是检索实验的唯一语料；同时供 `scripts/generate-capability-report.js` 做抽取式统计（关键词匹配，非 LLM 生成），产出**派生分析**报告 `reports/capability-analysis.md`——这是补充输出，不是本项目主旨。

## 收录原则（来源与真实性）

- **内容来源**：2026-08-06 通过搜索引擎检索得到的公开招聘信息。主流招聘站（BOSS 直聘、拉勾、猎聘）正文多为登录墙/JS 渲染，直接抓取不可行；公司官网招聘页在本环境被网络策略拦截。因此每份文档是基于公开检索结果整理的**职责/要求要点**，每份都标注「来源URL」与「抓取日期」。
- **宁少勿假**：只收录能追溯到来源 URL 的岗位；不确定的内容不编造。当前 11 份，覆盖大厂（腾讯×2、字节、京东、百度×2、美团、中国移动）、研究院（上海人工智能实验室）、外企（Apple×2），含社招/校招、C端/B端/平台/数据方向。
- **权利边界**：仅收录「岗位职责/任职要求」分析所需的最小文本片段，不收录完整招聘长文、薪资、联系方式。本目录内容是基于公开招聘来源整理的最小必要摘录，仅用于研究、教学与求职分析；**原始岗位文本及相关商标等权利归各自权利人所有，不包含在本仓库 MIT 授权范围内**。每份文档保留来源 URL 与整理日期，如权利人要求移除请联系维护者。

## 文件结构约定（scripts/generate-capability-report.js 依赖）

每份文档统一结构，脚本据此解析：

```
# <公司> · <岗位>

- 公司：<公司名>
- 岗位：<岗位名>
- 城市：<城市>
- 来源URL：<招聘来源链接>
- 抓取日期：YYYY-MM-DD
- 来源类型：公开招聘信息 · 搜索引擎聚合

## 岗位职责
- ...

## 任职要求
- ...

## 加分项
- ...

## 原始来源
- <平台>：<URL>
```

说明：脚本按 `## 岗位职责` / `## 任职要求` / `## 加分项` 三个小节解析（标题支持别名，如「工作职责」「职位要求」）。统计口径覆盖**岗位职责 + 任职要求 + 加分项**，报告中有明确说明。
