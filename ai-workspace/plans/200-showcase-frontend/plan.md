# 200 — PM 智能工作台展示前端

> [Qwen 2026-08-10] 状态：**待实现** | 负责：DeepSeek | 审查：Codex

## 一、问题定义

**现状**：项目有完整的后端能力（知识库检索、PRD 生成、Agent 工作流、能力分析报告），但只有一个静态 `index.html` 链接页。给 HR 展示时，只能打开终端跑 `node kb/search.mjs`，不直观。

**目标状态**：一个单页展示应用，HR 打开浏览器就能看到：
1. **实时检索演示**：输入框 + 搜索结果卡片（来源、分数、原文片段）
2. **能力分析报告**：可视化图表（11 个能力维度的柱状图）
3. **Agent 工作流展示**：六角色流程图 + 每个角色的说明
4. **多 AI 协作展示**：三个 AI 工具的分工 + 实时进度看板

**为什么重要**：这是 AI 产品经理求职作品集的核心展示物。HR 不会看终端输出，但会看一个漂亮的网页。

## 二、技术约束

| 约束 | 说明 |
|---|---|
| 运行时 | 纯前端（HTML + CSS + JS），或 Node.js 轻量后端 |
| 禁止 | React/Vue/Angular 等框架（增加复杂度）、数据库、构建工具链 |
| 部署 | 双击 `index.html` 可运行，或 `node server.mjs` 一键启动 |
| 风格 | 专业简洁，适合面试展示（参考 Apple/Notion 风格） |
| 响应式 | 必须支持笔记本和手机屏幕 |

## 三、技术方案

### 架构选型：Node.js 轻量后端 + 纯前端

**为什么不用纯静态**：知识库检索需要读文件系统（`kb/*.md`），纯前端无法直接读本地文件。

**方案**：
```
浏览器 (showcase.html)
  │ fetch('/api/search?q=xxx')
  ▼
Node.js 轻量服务 (server.mjs)
  │ 调用 kb/lib/indexer.mjs + retriever.mjs
  ▼
kb/*.md 文件
```

## 四、任务拆解（给 DeepSeek 的执行清单）

### Task 1：搭建后端服务（server.mjs）
- 用 Node.js 原生 `http` 模块（不引入 Express，保持 0 新依赖）
- 静态文件服务：返回 `showcase/` 下的 HTML/CSS/JS
- API 路由：`/api/search` 调用 `kb/lib/` 的 indexer + retriever

### Task 2：搜索交互界面

- 搜索结果渲染为卡片（来源文件、段落标题、相关度分数、原文片段高亮）
- Loading 状态 + 空结果提示
- **验证**：打开浏览器，输入"产品经理"，看到卡片结果

### Task 3：能力分析报告可视化
- 从 `AI产品经理能力分析.md` 读取数据（硬编码或解析）
- 纯 SVG 横向柱状图（不引入 Chart.js，保持 0 新依赖）
- 每个柱子显示：能力名称、硬性要求出现率、软性提及数
- **验证**：页面中间区域看到 11 个能力维度的柱状图

### Task 4：Agent 工作流展示
- 六个角色卡片：角色名、视角、一句话说明

- 点击角色卡片展开详细说明
- **验证**：看到六角色流程图，点击有交互

### Task 5：多 AI 协作看板
- 展示三个 AI 工具的分工（Qwen/DeepSeek/Codex）
- 显示当前任务进度（读 `ai-workspace/plans/` 下的 report.md）
- **验证**：看到三 AI 分工图和 001 任务的进度

### Task 6：样式打磨 + 响应式
- 统一配色（深蓝 + 白底 + 绿色强调）
- 移动端适配（搜索框和卡片堆叠）
- 动画：搜索结果的淡入、柱状图的填充动画
- **验证**：手机浏览器打开，布局正常

## 五、风险与回滚

| 风险 | 概率 | 应对 |
|---|---|---|
| 浏览器跨域问题（本地文件） | 中 | 通过 Node 后端代理，不走 file:// |
| 中文渲染乱码 | 低 | 确保 UTF-8 编码，meta charset 设置 |
| 大段原文撑破卡片 | 中 | snippet 截断 200 字 + CSS overflow + 展开按钮 |

**回滚**：所有新增文件在 `showcase/` 下，删除整个文件夹即可回滚。
